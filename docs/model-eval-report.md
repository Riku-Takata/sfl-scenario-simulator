### シーズンシミュレーションへの不確実性（誤差）反映

- 実力値の不確実性モデル（`uncertainty.ts`、既定値 $\sigma_0=100, \text{halfGames}=40$）から、モンテカルロ推計時に $K=200$ 通りの実力値の世界をサンプル。
- 同一の世界内では選手の好不調（実力値の誤差）が全試合で連動し、シーズンを通じたチームの好調・不調の波を正確に表現。
- **効果**:
  - 根拠ゲーム数が少ない選手や下振れリスクが順位確率に正しく反映され、極端に高く出すぎていた確率（例: ZETAの1位確率 84.9% → 82.1%、2位以内確保率 96.0% → 94.3%）が自然に緩和。
  - 各チームのプレイオフ進出確率の分布がより現実的かつ頑健な推計に改善。

### チームページでの「確率の内訳」表示

- 各チームページ（`/team/[teamId]`）に、残り試合ごとの詳細な予測と確率の内訳セクションを追加。
  - **試合ごとの予想勝率・期待獲得ポイント・最有力スコア**
  - **最も起こりやすい対戦カード ＆ 各ボウトの勝率計算根拠**（実力差、キャラ相性、HOME/AWAY補正）
  - **発生しやすい組み合わせ Top 3**（出場選手モデル推計による組み合わせ発生率とボウト勝率）
  - **各選手のポジション別出場確率**（先鋒率・中堅率・大将率・総合出場率）
