# Gemini用：SFL Division F 第4節アーカイブ解析

## 使い方

1. [Gemini](https://gemini.google.com/) の通常チャットを開き、下の「貼り付けるプロンプト」全体を送ってください。
2. プロンプトには公式アーカイブURLを含めています。Geminiが動画を参照できない、または10対戦すべてを確認できない場合は、その旨を返すよう指示しています。未確認部分を推測で埋めないでください。
3. 回答を `.md` ファイルとして保存し、このCodexタスクに添付してください。添付後、公式結果・キャラクター・ラウンド推移と照合し、根拠が取れる内容だけを編集原稿に反映します。

Gemini AppsはYouTube動画について質問できますが、利用条件や動画の公開情報に左右されます。動画全編を実際に確認できたか、各対戦・各場面に対応した時刻を出せるかを回答内で明示するようにしています。[Gemini Apps ヘルプ：YouTubeコンテンツについて質問する](https://support.google.com/gemini/answer/16622858?hl=en)

## 最優先ルール

- まず、このURLの動画を実際に参照できるか確認してください。参照できない、または一部しか確認できない場合は、対象を明記してそこで止め、映像を見たふりをしないでください。
- 各対戦について、映像で実際に確認できた場面だけを具体的に記述してください。結果やキャラクター情報は下の公式ログを照合用に使い、映像から見えない攻防を補ってはいけません。
- 動画から確認した出来事には、必ずアーカイブ全体の時刻を `hh:mm:ss` で付けてください。可能なら複数の出来事にそれぞれ時刻を付けます。時刻が特定できなければ「時刻特定不可」とし、推定時刻を書かないでください。
- 映像で直接見たこと、実況・解説が述べた評価、公式ログから分かる結果、そこから導く編集上の解釈を区別してください。実況の見立ては、必要なら「解説は〜と評した」と帰属させてください。
- 勝敗が一致しただけで技名・攻防・因果関係が正しいとは判断しないでください。技名・プレイヤー・ラウンド・試合番号に自信がなければ、不確実と明記するか記述を省いてください。
- 心理、事前準備、相手対策の意図を創作しないでください。「狙った」「読んだ」「対策した」と書くのは、映像または実況から確認できる場合だけです。
- 攻防の網羅的な文字起こしではなく、勝敗に関係する局面を選んでください。特定の選手のプレーを褒めるだけでなく、何が起き、それが相手の選択やラウンド結果にどうつながったかを書いてください。
- 公式ログと映像で食い違いがあれば、どちらかに黙って合わせず「要確認」として、時刻と相違点を記録してください。
- 10対戦すべてを確認できない場合、未確認対戦も項目だけは残し、本文は「未確認」としてください。確認できた対戦だけを完成扱いにします。

## 見てほしい観点

各対戦について、確認できる範囲で次を調べてください。

1. 試合の立ち上がりと両選手が実際に使った選択肢（例：牽制、対空、差し返し、投げ、パリィ、ドライブインパクト、バーンアウト、画面端からの脱出）。映像で確認できたものだけ。
2. 相手がそれにどう応じたか。対応が変化したなら、変化が見えたゲーム・ラウンドと時刻。
3. 流れを変えた、または勝者の主導権を保った具体的な場面。転機が見つからない場合は、優勢が続いた理由として確認できた行動を書く。
4. 決着の局面と、その攻防が勝敗にどう結び付いたか。
5. 実況・解説に勝因や見どころへの具体的な言及があれば、その要旨、発言のおおよその時刻、映像事実との関係。
6. チーム戦では、この対戦の勝敗がチームポイントの推移（先鋒・中堅・大将・延長）にどう影響したか。これは公式結果から説明し、試合順を取り違えないこと。
